# Vrida Store Sales Dashboard

## 📊 Project Overview

Vrida Store Sales Dashboard is an interactive Microsoft Excel data analytics project designed to analyze store sales performance and generate meaningful business insights.

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Key Analysis

- Sales performance analysis
- Product-wise sales
- Customer analysis
- Regional performance
- Monthly sales trends
- Order analysis
- Top-performing products
- Sales category analysis

## 📊 Dashboard

The dashboard provides interactive visualizations using PivotCharts and slicers to help users explore sales data.

## 💡 Business Insights

The analysis helps identify:

- Best-performing products
- High-performing regions
- Sales trends
- Customer purchasing patterns
- Opportunities for improving sales performance
